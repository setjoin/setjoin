# Recording transaction/publication adapter

Reserved package setjoin-recording at server-rust/crates/domains/recording; authored privately. Path-only dependencies are the exact retained contracts and db sources in MEETING-ADAPTER-ALLOCATION-02. Qualification copies that tree without editing its retained crate sources. Only the private workspace members list adds this crate.

The recording wrapper reuses CommitObservation/ConnectionDisposition, not TransactionLifecycle or its unrelated accepted_contract. RecordingStore::transact is an injected serialized transaction boundary: operation identity lookup by operation ID, locks, authorization and final fence held through commit, rollback on every closure error, and clean connection per receipt lookup. RecordingTx exposes exact retained facts, trusted content verification, reference lock, atomic publication bundle, immutable evidence append and commit fence. These are explicit driver obligations, not a claim that DTO equality or public flags establish authorization. The test fixture supplies these obligations in memory; it is not a PostgreSQL implementation.

PublishRecording::plan verifies fresh exact content/publication, actor/scope and capture/participant generations. ReferenceState::plan attaches the immutable reference once. The transaction stages node/version/reference/Ready/journal/audit/event together. A previously journaled identical request returns the original receipt after current authorization and fence; changed input refuses. Ready without its original journal reconciles and never fabricates a receipt. Lookup opens a separate clean transaction; missing data never permits capture/resend. Unknown commit suppresses all staged output, quarantines the original connection and retains staging. Known terminal responses require reset verification; only known committed receipt returns RemoveAfterAcceptedCommit. No physical deletion, external effect or download capability exists here.

Provider evidence must already be authenticated by a trusted observer. Immutable contradictory observations remain retained and reconciliation-required; no auto-clear or provider business settlement. Authority/reference generation values are bounded to BIGINT at this adapter boundary. ReferenceState's hold semantics permit attach while held; trusted verifier additionally enforces the applicable publication hold policy. Replays return receipts and grant no fresh content access.
