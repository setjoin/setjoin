# setjoin-edge-contract — DOX

## Purpose

Edge-only plain `serde` DTO crate generated deterministically from `contracts/edge/openapi/edge.v1.yaml` (authored in TypeSpec under `contracts/edge/`).

## Local contracts

- `#![forbid(unsafe_code)]`.
- Plain `serde::Serialize` / `serde::Deserialize` DTOs only — **zero** OpenAPI proc-macro crates (`utoipa`, `aide`, `poem-openapi`, `schemars`, etc.), enforced by `scripts/guards/check-openapi-proc-macro-ban.sh`.
- Zero database, SQL, I/O, or credential dependencies; never imports any `crates/domains/*` or `crates/pg` crate.
- `src/generated.rs` is generated by `npm run build` in `contracts/edge/` and verified byte-identical by `scripts/guards/check-edge-contract-drift.sh`.

## Verification

- `cargo test --locked -p setjoin-edge-contract`
- `bash scripts/guards/check-edge-contract-drift.sh`
- `bash scripts/guards/check-openapi-proc-macro-ban.sh`
