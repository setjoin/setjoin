# mailctl — admin CLI (DOX child)

Frozen Go parity reference since #355. Customer builds use the
[Rust CLI contract](../server-rust/bins/mailctl/DOX.md); this rail governs the Go oracle source.

Owns the separate operator CLI module; never import mailserver/internal. Dispatch registry owns help/flags/backend/lazy connections; offline verbs must not gain server dependencies. Preserve per-command DSN precedence, destructive confirmation and explicit --yes semantics. Credential config is 0600; SCIM plaintext appears once and is not stored plaintext in DB. JSON stdout, error stderr, stable nonzero exits and typed APIError decoding are contracts. All REST/streams use apiPath; preserve pinned prefixes. Guard incomplete argv. Read affected command and security/release contracts before upgrade/recovery/artifact changes; query work requires DATABASE_SECURITY.
