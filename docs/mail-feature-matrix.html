📋 Competitive Roadmap — 3 Stages

Stage 1 — Enterprise Deal-Qualifier (0–6 months)

  1. Native iOS + Android apps — Phase 12, spec exists. Push, offline, MDM via JMAP.
  2. Number-match push MFA — Replace tap-to-approve with 2-digit challenge.
  3. Link protection (time-of-click URL rewriting) — Safe Browsing API integration.
  4. Attachment sandbox/detonation — CAPE/Cuckoo sandbox integration.
  5. Undo send + snooze/pin-to-top — Snooze already modeled in Phase 17 tag system.
  6. External-sender warning banners — Configurable HTML banner for external mail.
  7. Per-alias signatures + internal message recall — Competitive checkbox.
  8. Chinese-language admin UI + docs — i18n infrastructure for Chinese market.

Stage 2 — Regulated-Industry Ready (6–12 months)

  1. Journaling + full envelope capture — BCC, headers, RFC envelope. Mandatory for regulated.
  2. eDiscovery + content search — KQL search, export, case management.
  3. WORM immutability — S3 Object Lock at SeaweedFS layer. SEC/FINRA compliance.
  4. Advanced anti-phishing — Display-name spoofing, lookalike domains, mailbox intelligence.
  5. SCIM provisioning — Automated user lifecycle from Entra ID/Okta.
  6. OIDC client-type discrimination — Public vs confidential, PKCE enforcement.
  7. SMTP inbound DANE + DNSSEC — Cryptographic TLS guarantee for mail flow.

Stage 3 — Global Platform (12–18 months)

  1. Xinchuang (信创) certification — Domestic CPUs, OSes, DBs for Chinese gov/SOE.
  2. National crypto SM2/SM3/SM4 — Classified communications compliance.
  3. AI email features — Smart compose, reply, auto-tagging via local LLM.
  4. Conference/room booking calendar UI — Scheduling grid with availability.
  5. Conditional access policy engine — Risk-based step-up, device posture.
  6. Enhanced mobile MDM — Remote wipe, PIN enforcement, app-level policies.
