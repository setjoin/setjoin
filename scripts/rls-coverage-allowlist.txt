# rls-coverage-allowlist.txt — the human-maintained RLS-coverage classification
# read by scripts/check-rls-coverage.sh (W7 / 2026-06-18-native-rls-backstop.md).
#
# Every backtick / double-quoted SQL literal in mailserver/internal (non-test)
# that touches any table in the runtime-derived FORCE'd set (extracted from
# mailserver/sql/dbschema V*.sql by the guard since D-1,
# 2026-09-18-debt-consolidation.md) must have an entry here, classifying HOW
# that site is covered against the FORCE flip. A site with no entry FAILS the
# guard.
#
# FORMAT (TAB-separated, 4 fields):
#   <basename>\t<CLASS>\t<unique lowercase substring>\t<reason>
#   · <basename>   — the .go file's basename (entry matches only in that file).
#   · <CLASS>      — one of: WRAPPED | BYPASS | AUDITED-XTENANT  (informational;
#                    the guard treats all three as "classified". The class +
#                    reason are the human audit trail a reviewer checks.)
#   · <substring>  — a unique LOWERCASE substring of the comment-stripped,
#                    whitespace-collapsed SQL literal. Must be present (lowercased)
#                    in the literal for the entry to match. Pick something stable
#                    + distinctive so a SQL edit that changes the touched columns
#                    re-trips the guard for re-review.
#   · <reason>     — one line. For BYPASS, NAME the main.go construction line.
#
# CLASS meanings:
#   WRAPPED         — the call runs inside a transaction that first set
#                     app.current_mailbox_id (jmap CallScoped / imap withScope /
#                     a hand-rolled inline `Begin → set_config(...) → tx.*`). Under
#                     FORCE the GUC scopes the rows to the authenticated mailbox.
#   BYPASS          — the handler is constructed on workerPool (BYPASSRLS), so the
#                     query is exempt from RLS at the DB. Name the main.go line.
#   AUDITED-XTENANT — intentionally reads/writes across mailboxes on the bypass
#                     pool (admin eDiscovery/monitor, outbound drain, spam). A
#                     human confirmed the cross-tenant scope is by design.
#
# Lines beginning with `#` (and blank lines) are ignored.
#

# enumerated list is the Phase-2 (W7) work item. Phase 2 wraps/routes each site
# and adds its classified entry here. Do NOT pre-populate to make the guard pass
