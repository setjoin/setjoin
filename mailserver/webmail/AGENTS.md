# Webmail — AGENTS.md (DOX child)

Owns SvelteKit presentation, routes/stores/clients/i18n/tokens; reducers/gateway own authority. Use Svelte 5 runes, strict TS, onclick, UI barrel and tokens; no legacy glass/reactivity. Preserve accessibility, focus-stack ownership and async loading/error/success/duplicate-submit behavior. Visibility comes from effective session capabilities, never authorization. JMAP has one capability table; preserve mailbox selection and auth-generation fencing. JSON uses api/pinned prefixes and adminFetch seam. Service worker caches only generated public assets. Native bridge only via $lib/native with capability/version checks. Preserve CSP owners, self-hosted fonts/models, safe HTML, guest secrecy and bounded OIDC continuation. EN/ZH switching must not remount or eagerly import all catalogs. UI changes read DESIGN.md and affected feature; code checks require zero warnings. Children: src/lib/components/ui/AGENTS.md and e2e/AGENTS.md.
